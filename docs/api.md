# BotLR API

Base URL: `https://api.botlr.io/v1` (prod) / `http://localhost:8000/v1` (local)

**Authentication:**
- Dashboard: JWT Bearer (`Authorization: Bearer <token>`)
- Webhooks: Provider signature verification (no JWT)

> **Note:** Full OpenAPI spec auto-generated by FastAPI at `/docs` endpoint.

## Endpoints

### Webhooks
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | /webhooks/whatsapp | Signature | Receive WhatsApp message (Twilio / 360dialog) |

### Auth
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | /auth/login | None | Authenticate seller |
| POST | /auth/register | None | Register seller (invite token) |
| POST | /auth/refresh | Cookie | Rotate access token |

### Orders
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | /orders | JWT | List seller's orders |
| GET | /orders/{id} | JWT | Get single order |
| PATCH | /orders/{id}/status | JWT | Update order status |

### Products
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | /products | JWT | List seller's products |
| POST | /products | JWT | Create product |
| GET | /products/{id} | JWT | Get product |
| PATCH | /products/{id} | JWT | Update product |
| DELETE | /products/{id} | JWT | Soft-delete product |
| POST | /products/{id}/image | JWT | Upload image (multipart) |

### Sellers
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | /sellers/me | JWT | Get current seller |
| PATCH | /sellers/me | JWT | Update seller profile |

### Real-time
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | /events/orders | JWT | SSE stream for order updates |

### Health
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | /health | None | Liveness and readiness |

```json
{
  "error": {
    "code": "ORDER_NOT_FOUND",
    "message": "The requested order does not exist.",
    "status": 404,
    "detail": { "order_id": "abc-123" }
  }

```

## SSE Events

| Event | Payload | Description |
|-------|---------|-------------|
| `order.created` | `{ order_id, status, customer_name }` | New order from WhatsApp |
| `order.updated` | `{ order_id, status, previous_status }` | Status changed |
| `order.completed` | `{ order_id, completed_at }` | Order marked completed |
| `ping` | `{ ts }` | Keep-alive every 30s |
